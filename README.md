# 3RD WORLD

Custom global streetwear commerce platform.

## Build plan
1. Brand / UX / Architecture
2. Frontend Experience
3. Commerce Core + Admin
4. Checkout + Payments + Global Commerce
5. 3RD WORLD Systems
6. Hardening + Launch

## Current status
- Phase 01: direction locked
- Phase 02: custom frontend foundation implemented on `phase-02-frontend`

## Phase 02 scope
- Next.js + React + TypeScript
- Custom design system
- Responsive global navigation
- Home
- Shop
- Product detail
- Drop / access screen
- Archive
- World
- Passport
- Search
- Bag drawer
- Mobile-first behavior
- Reduced-motion support
- No Shopify or storefront template dependency

## Local development
```bash
npm install
npm run dev
```

Open http://localhost:3000.

Commerce, inventory, checkout processing, payments, global markets and the private admin are intentionally reserved for later phases.
